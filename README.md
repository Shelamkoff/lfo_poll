# Анкета: выбор ОПФ и подготовка устава

Интерактивная анкета на русском языке для предварительного выбора организационно-правовой формы и сбора сведений для разработки индивидуального устава. Работает как статическая HTML-страница, без сервера и сторонних зависимостей.

## Возможности

- **Единый вводный раздел** о целях проекта, деятельности и участниках.
- **Предварительная рекомендация ОПФ** с пояснением причин.
- **Проверка допустимости формы:** недоступные варианты отключены с указанием причины (например, недостаточное число учредителей).
- **Выбор всех подходящих форм**, без ограничения двумя вариантами.
- **Независимые разделы устава** для каждой выбранной ОПФ; свободное переключение между ними через навигацию.
- **Проверка обязательных ответов** перед переходом вперёд внутри разделов.
- **Числовые поля с ограничениями**, в частности капитал ООО от 10 000 рублей.
- **Юридические пояснения** и ссылки на нормы закона.
- **Печатная версия** с ответами по всем формам.
- **Экспорт Markdown и JSON**, повторная загрузка JSON и сохранение промежуточных ответов.

## Использование

Откройте [index.html](index.html) в современном браузере или страницу GitHub Pages:

<https://shelamkoff.github.io/lfo_poll/>

Сначала заполните общий раздел, затем выберите подходящие ОПФ. Каждая выбранная форма появится в навигации; её уставные вопросы будут заполняться независимо от других. Для ИП устав не требуется.

Для продолжения заполнения после закрытия вкладки сохраните JSON-файл и позже загрузите его через раздел результатов.

## GitHub Pages

Если публикация ещё не включена: **Settings → Pages → Deploy from a branch → master / (root) → Save**.

После обновления `master` GitHub Pages может обновляться с задержкой. Сам факт коммита не подтверждает, что на публичном сайте уже размещена новая версия.

## Юридические ограничения

Подбор ОПФ и автоматические проверки носят предварительный характер. Выбор формы зависит не только от ответов, но и от применимого специального регулирования. Полностью заполненная анкета — исходные сведения для подготовки устава, **не готовый юридически проверенный устав и не регистрационный пакет**. Для отдельных кооперативов, СРО и регулируемых видов деятельности необходим специальный правовой анализ.

## Конфиденциальность

Анкета не отправляет введённые ответы на сервер. Ответы остаются в открытой вкладке браузера до её обновления или закрытия, если пользователь не сохраняет JSON. Избегайте внесения паспортных данных и конфиденциальных документов в свободные поля.

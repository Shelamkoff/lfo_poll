# Анкета: выбор ОПФ и подготовка устава

Интерактивная анкета на русском языке для первичного подбора организационно-правовой формы и сбора исходных данных для подготовки устава. Приложение работает как статическая страница без сервера и сторонних зависимостей.

## Функции

- предварительная рекомендация ОПФ по ответам о целях, участниках и прибыли;
- выбор **одной или двух** форм с последовательным заполнением;
- отдельные ответы для ООО, ассоциации, АНО и иных предусмотренных форм;
- раскрывающиеся юридические пояснения и ссылки на нормативные источники;
- печатный отчёт с ответами по выбранным формам;
- экспорт в JSON и TXT, повторная загрузка JSON (поддерживается импорт из предыдущей версии анкеты).

## Конфиденциальность и юридическая проверка

Ответы не передаются на сервер и не сохраняются в GitHub. Они хранятся во вкладке до её закрытия либо перезагрузки; для продолжения рекомендуется сохранить JSON. Не вводите паспортные данные и конфиденциальные документы в свободные поля. Рекомендация ОПФ предварительная: перед регистрацией юрист проверяет учредительные документы, применимые специальные законы и комплект документов.

# Анкета для выбора организационно-правовой формы и подготовки устава

Интерактивная русскоязычная анкета для предварительного выбора ОПФ и сбора исходных сведений для проекта индивидуального устава. Статическая HTML-страница без серверной части и сторонних зависимостей.

**Страница:** https://shelamkoff.github.io/lfo_poll/

## Возможности

- Общий вводный раздел, одинаковый для всех рассматриваемых ОПФ.
- Рекомендация правовой формы на основании ответов и объяснение недоступности форм, несовместимых с исходными условиями.
- Неограниченный выбор нескольких допустимых форм; переключение между их разделами через единую навигацию.
- Самостоятельный набор вопросов для каждой выбранной организации. ИП не имеет устава и не заполняет уставные разделы.
- Валидация обязательных вопросов при переходе к следующему шагу; проверка установленных законом ограничений.
- Разделение правовых обязательных положений устава и дополнительных, выбираемых по усмотрению.
- Ссылки на статьи ГК РФ, законов № 14-ФЗ, № 7-ФЗ, № 82-ФЗ и иных применимых актов.
- **Только печать и экспорт в Markdown.** Кнопок импорта/экспорта JSON и удаления заполненных ответов нет.

## Использование

Откройте `index.html` в современном браузере или воспользуйтесь GitHub Pages.

1. Ответьте на общие вопросы о проекте и предполагаемых участниках.
2. Выберите одну или несколько доступных ОПФ. Неподходящие формы будут недоступны с пояснением юридической причины.
3. Заполните вопросы каждой выбранной организации; при необходимости переключайтесь между ними в боковом меню.
4. В разделе «Итоги и документы» проверьте замечания и распечатайте ответы либо скачайте Markdown.

**Важно:** анкета не сохраняет ответы между обновлениями и закрытиями вкладки. Для сохранения сведений скачайте Markdown или распечатайте результат до закрытия страницы. Markdown — текстовая копия ответов, **не** файл для повторной загрузки.

## Публикация через GitHub Pages

Содержимое размещается непосредственно в `master`: в корне лежат `index.html` и `.nojekyll`. Если Pages настроен на **Deploy from a branch → master / (root)**, обновление `master` запускает публикацию автоматически. Между коммитом и обновлением публичной страницы возможна задержка.

## Правовые ограничения

Анкета предназначена для **предварительного подбора ОПФ и подготовки задания на проект устава**, а не для автоматического составления юридически готового устава. Законность конкретных формулировок зависит от состава учредителей, предмета деятельности, способа управления и специальных требований закона. Даже если все обязательные поля заполнены, перед утверждением устава, реорганизацией или подачей документов в регистрирующий орган необходима юридическая проверка.

Особого правового анализа требуют потребительские кооперативы специального вида, СРО, финансовые организации, объединения работодателей, спортивные федерации, религиозные организации и лицензируемая деятельность.

Сведения о юридической ревизии и её пределах приведены в [LEGAL_AUDIT.md](LEGAL_AUDIT.md).

## Конфиденциальность

Анкета работает локально в браузере: введённые сведения не отправляются на сервер. При этом на странице не предусмотрено постоянное хранение ответов в локальном хранилище браузера. Не вводите паспортные данные и конфиденциальные сведения в произвольные текстовые поля.
